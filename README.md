# Cadastro de Usuários
Projeto simples de cadastro de usuários desenvolvido com HTML, CSS e JavaScript.

## Sobre o projeto
Este projeto foi criado para praticar conceitos básicos de desenvolvimento web, 
incluindo estruturação de páginas, estilização e manipulação de dados com JavaScript.

## Funcionalidades
- Cadastro de usuários
- Interface simples e organizada
- Listagem de usuários cadastrados
- Manipulação do DOM

## Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript

## Objetivo
Praticar lógica de programação, interação com formulários e criação de interfaces web.

## Aprendizados
Durante este projeto foram praticados:
- Estrutura HTML
- Estilização com CSS
- Eventos no JavaScript
- Manipulação de elementos
- Organização de código
